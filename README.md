# ⛏️ FiveM Farming Macro (Background Automation & Remote Control)

โปรแกรมมาโครฟาร์ม FiveM ทำงานเบื้องหลัง (Background Mode) ครบวงจร พร้อมระบบสั่งการควบคุมระยะไกลผ่าน **Discord Bot**, ระบบนำทางปักหมุดแผนที่อัจฉริยะ, ระบบเบิกรถ และระบบขับรถอัตโนมัติ

---

## 🌟 คุณสมบัติเด่น (Key Features)

### 1. 🗺️ ระบบนำทางและปักหมุดแผนที่อัจฉริยะ (Map Navigation)
* **!map1 (จุดขุด Mine Job):**
  * เปิดแผนที่ (P) ➔ เข้าสู่มุมมองแผนที่ (Enter)
  * เลื่อนลูกศรขึ้น (Up Arrow) ย้อนจากล่างขึ้นมาเพื่อความรวดเร็วและแม่นยำ
  * สแกนตรวจจับแถบ **Mine Job 🚚** (ความแม่นยำสูง ไม่หลงติดแถบงานอื่น)
  * กด Enter 1 ครั้งเพื่อปักหมุดม่วง Waypoint ➔ กด P ออกจากแผนที่ทันที
* **!map2 (พาวรถ Car Pound):**
  * เปิดแผนที่ (P) ➔ สแกนหา **Car Pound**
  * กดลูกศรขวา (Right Arrow) เพื่อสลับเป็น **❮ 2/2 ❯**
  * ปักหมุด Waypoint และออกจากแผนที่อัตโนมัติ

---

### 2. 🚗 ระบบยานพาหนะและการเดินทาง (Vehicle Automation)
* **!car (เบิกรถอัตโนมัติ):**
  * กดปุ่ม **E ค้าง 2.0 วินาที** เพื่อเปิดเมนูการาจ (Open Garage)
  * สแกนหาการ์ดรถและคลิกเลือกการ์ดรถทันที
  * สแกนหากดปุ่มสีน้ำเงิน **Select Vehicle** เพื่อสั่งเบิกรถ
  * รอรถเกิดและขึ้นรถ 4.0 วินาที ➔ **กดปุ่ม B เพื่อรัดเข็มขัดนิรภัยอัตโนมัติ** 🔒
* **!drive (ขับรถอัตโนมัติ):**
  * กดปุ่ม **- (หรือ ข)** เพื่อเปิดเมนูควบคุมรถ
  * สแกนและคลิกปุ่ม **Auto Drive** เพื่อเริ่มขับรถตามหมุด Waypoint ทันที
  * **กดปุ่ม ESC 1 ครั้ง** เพื่อปิดเมนูควบคุมรถทันที

---

### 3. ⛏️ ระบบฟาร์มและจัดการไอเทม (Core Farming Engine)
* 🟢 **Background Mode:** ทำงานเบื้องหลังได้โดยไม่ต้องดึงจอ FiveM มาบังหน้าจอหลัก
* 🍗 **ระบบกินข้าว/น้ำอัตโนมัติ (Auto-Feed):** ตรวจจับหลอดอาหารและน้ำ หรือกดช่อง 6 (น้ำ) และช่อง 7 (อาหาร) เมื่อค่าต่ำกว่าเกณฑ์
* 💎 **ระบบเก็บเพชรลงท้ายรถ (Auto-Store Diamonds):** รองรับทั้งแบบรอบเวลาทุก 40 นาที หรือแจ้งเตือนเมื่อกระเป๋าเต็ม 40/40
* 🗑️ **ระบบทิ้งทอง (Auto-Discard Gold):** เปิดกระเป๋า ลากทองไปที่ถังขยะ และกดยืนยันอัตโนมัติ

## 📱 ตารางคำสั่งควบคุมผ่าน Discord Bot (Remote Commands)

| คำสั่ง (Prefix เริ่มต้นคือ !) | คำสั่งย่อ / ภาษาไทย | รายละเอียดการทำงาน |
| :--- | :--- | :--- |
| **!help** | !คำสั่ง, !เมนู | แสดงเมนูและรายการคำสั่งทั้งหมด |
| **!เข้าเกม [IP/cfx]** | !connect, !join | สั่งเปิด FiveM และเชื่อมต่อเข้าเซิร์ฟเวอร์ทันที |
| **!map1** | !mark1, !มาร์ค1 | ปักหมุด Waypoint ไปยังจุดขุดเหมือง (Mine Job 🚚) |
| **!map2** | !mark2, !พาวรถ | ปักหมุด Waypoint ไปยังพาวรถ (Car Pound 2/2 🚗) |
| **!car** | !เบิกรถ, !spawn | เปิดการาจ (E ค้าง 2วิ) ➔ เลือกรถ ➔ เบิกรถ ➔ รัดเข็มขัด (B) |
| **!drive** | !ขับออโต้, !autodrive | กด - (ข) ➔ คลิกเปิด Auto Drive ➔ กด ESC ปิดเมนู |
| **!check** | !bag, !กระเป๋า, !ทอง | เปิดกระเป๋า ตรวจเช็คไอเทม/ทอง/เพชร และถ่ายรูปส่งกลับมา |
| **!close** | !t, !ปิดกระเป๋า, !ปิด | สั่งกดปุ่ม T เพื่อปิดกระเป๋าทันที |
| **!discard** | !ทิ้งทอง | สั่งทิ้งทอง กดยืนยัน และกลับไปเริ่มฟาร์มต่อให้อัตโนมัติ |
| **!screen** | !จอ, !ภาพ | ถ่ายภาพหน้าจอ FiveM สดๆ ส่งกลับมาในห้องแชท |
| **!status** | !สถานะ | ตรวจสอบสถานะการทำงาน, เลือด, น้ำ/อาหาร, สถานะเพชร |
| **!start** | !เริ่ม | สั่งเริ่มการทำงานของมาโคร (เทียบเท่าปุ่ม F9) |
| **!stop** | !หยุด | สั่งหยุดพักมาโครชั่วคราว (เทียบเท่าปุ่ม F9) |
| **!feed** | !กินข้าว | สั่งให้ตัวละครกินน้ำ (ช่อง 6) และอาหาร (ช่อง 7) ทันที |
| **!store** | !เก็บเพชร | สั่งเปิดท้ายรถและเก็บเพชรลงรถทันที |

> 💡 **หมายเหตุ:** สามารถตั้ง Prefix แยกในแต่ละเครื่องได้ (เช่น !, ?, !2) และรองรับการสั่งงานผ่าน DM (ข้อความส่วนตัว) หาบอทได้โดยตรง

## 🖥️ ปุ่มควบคุมบนหน้าต่างโปรแกรม (GUI Panel)

* **[ 📍 map1 (จุดขุด) ]**: ทดสอบการปักหมุดจุดขุด Mine Job
* **[ 🚗 map2 (พาวรถ) ]**: ทดสอบการปักหมุดพาวรถ Car Pound
* **[ 🚙 เบิกรถ ]**: ทดสอบการกด E ค้าง 2วิ ➔ เลือกเบิกรถ ➔ รัดเข็มขัด
* **[ 🚘 ขับออโต้ ]**: ทดสอบการกด - ➔ เปิดระบบ Auto Drive ➔ กด ESC
* **[ 🎯 พิกัด ]**: บันทึกพิกัด/ครอปไอคอนจุดมาร์คด้วยตนเอง
* **[ 🔄 ออโต้ ]**: รีเซ็ตระบบมาร์คแมพกลับเป็นโหมดสแกนภาพอัตโนมัติ

---

## ⌨️ คีย์ลัดหลัก (Hotkeys)

* **F9**: เริ่ม / หยุดการทำงานของมาโครฟาร์ม
* **P**: เปิด / ปิด แผนที่ (Pause Menu Map)
* **- (ข)**: เปิดเมนูควบคุมยานพาหนะ (Vehicle Control)
* **E (ค้าง 2.0s)**: เปิดเมนูเบิกรถการาจ
* **B**: รัด / ปลด เข็มขัดนิรภัย

---

## 🚀 การติดตั้งและเริ่มใช้งาน

1. เปิดใช้งาน **FiveM** และเชื่อมต่อเข้าเซิร์ฟเวอร์
2. เปิดโปรแกรม **FiveM Farming Launcher** หรือรันไฟล์มาโคร
3. โปรแกรมจะตรวจจับหน้าต่างเกม FiveM อัตโนมัติ (ไฟแสดงสถานะจะเปลี่ยนเป็นสีเขียว 🟢)
4. ปรับแต่งการตั้งค่าที่ต้องการในแท็บ **ตั้งค่า** หรือสั่งงานผ่าน **Discord Bot** ได้ทันที
